# mi-portafolio

Soy un desarrollador web Full Stack de 22 años y actualmente trabajo en Hannah Lab. Mi principal fortaleza es el frontend, creando interfaces modernas y responsivas. Estoy fortaleciendo mis conocimientos en backend. En este repositorio presento mi portafolio personal, donde comparto mis proyectos, habilidades y crecimiento profesional.

**Sitio publicado:** [fabricio-orihuela.vercel.app](https://fabricio-orihuela.vercel.app)

## Qué incluye

- Presentación, experiencia y educación.
- Proyectos con enlaces a su repositorio y a su demo.
- Habilidades agrupadas por categoría, con iconos.
- Contacto por WhatsApp, correo, LinkedIn y GitHub.
- CV descargable en PDF.
- Diseño responsive, con navegación por teclado y buenas puntuaciones en Lighthouse (accesibilidad, buenas prácticas y SEO: 100).

## Tecnologías

- [Next.js](https://nextjs.org) 16 y [React](https://react.dev) 19
- [TypeScript](https://www.typescriptlang.org)
- [Tailwind CSS](https://tailwindcss.com) 4
- [lucide-react](https://lucide.dev) y [react-icons](https://react-icons.github.io/react-icons/) para los iconos
- Publicado en [Vercel](https://vercel.com)

## Cómo ejecutarlo en local

Requiere [Node.js](https://nodejs.org) instalado.

```bash
git clone https://github.com/Fabricio2106/mi-portafolio.git
cd mi-portafolio
npm install
npm run dev
```

Luego abre [http://localhost:3000](http://localhost:3000) en el navegador.

| Comando | Qué hace |
| --- | --- |
| `npm run dev` | Inicia el servidor de desarrollo |
| `npm run build` | Compila el sitio para producción |
| `npm start` | Sirve la versión compilada |
| `npm run lint` | Revisa el código con ESLint |

## Estructura

```
app/
  components/   Secciones de la página (Navbar, Hero, About, Projects, Skills, Contact, Footer)
  data/         Datos de contacto
  globals.css   Colores, fuentes y animaciones
  layout.tsx    Metadatos y estructura base
  page.tsx      Página principal
cv/             Código fuente del CV (HTML) para generar el PDF
public/         Archivos públicos, como el CV en PDF
```
